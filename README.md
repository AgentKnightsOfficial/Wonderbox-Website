# WonderBox website

Static website for WonderBox, a student-run nonprofit that delivers free care packages to hospitalized children.

## Files

- `index.html` is the home page.
- `about.html` is the About us page with the mission statement and team.
- `wonderbox-logo.png` is the logo.

No build step is needed. Open `index.html` in a browser to preview.

## Common edits

- Donate link: search for `givebutter.com` in both HTML files.
- Contact email: search for `wonderboxnpo@gmail.com`.
- Box contents: edit the three `panel` sections in `index.html`.
- Team bios: edit the `member` cards in `about.html`.

## Publishing

Host it for free with GitHub Pages: in the repository, go to Settings, then Pages, and choose the `main` branch and the root folder.
